# 프롬프트·요구사항 변경 역사

Cursor 대화에서 사용자가 남긴 요청을 시간순으로 묶어, **무엇을 요청했는지 → 어떻게 바뀌었는지**를 정리한 문서입니다.  
원문 대화 로그는 로컬 agent transcript에만 있으며, 이 문서는 제품 이력용 요약입니다.

기준 스냅샷: **v3.5.0** (2026-07-31)

---

## 1. 로그인·세션 (초기)

| 요청 | 결과 방향 |
|------|-----------|
| 로그인 필요 페이지를 어떻게 처리할지 (소셜/미리 로그인) | 미리 로그인·세션 유지 UX 방향 검토 |
| 1단계에 로그인 완료/세션 유지 표시 | 사이트 입력 단계 로그인 상태 UI |
| Live View만으로는 느리고 불편 | Live View 의존 축소, 캡처/미리보기 중심 UX |

## 5. URL 발견 (사이트 입력)

| 요청 | 결과 방향 |
|------|-----------|
| 도메인만 넣으면 하위 URL 전부? | Firecrawl map + sitemap 기반 발견 기능 도입 |
| 타임아웃·선택 UX | NDJSON 스트리밍으로 발견 즉시 표시, 타임아웃 시 중단(자동 재시도 없음) |
| 서브도메인 체크 의미 | 라벨/툴팁 명확화 (기본은 입력 도메인만) |
| 프로젝트 전환 시 시드/발견 잔존 | `resetDiscoverForProject` + 세션 리셋 |

## 6. 공통·택소노미·페이지뷰 (최근 핵심)

| 요청 | 결과 방향 |
|------|-----------|
| 공통 조건이 뭐냐 / GNB allowlist 불만 | **전 화면(페이지×뷰포트)에 동일 카/액/라면 공통** — 이름 if문 제거 |
| 태그 목록 세로 나열 불편 | 페이지별 탭 |
| 페이지뷰에 카/액/라 넣지 말 것 | 파라미터에서 제거, **`page_name`** 추가 |
| 엑셀 보기 좋게 / 후보·개수 불필요 | 컬럼: 이벤트명·시점·카테고리·액션·라벨·설명 + exceljs 스타일 |
| 요소번호(tag_id) 오버레이 제거 | 미리보기에서 번호 숨김, 다중 멤버 **union bbox** |
| 택소노미에도 카엑라(페이지뷰)·발생시점/설명 | 공통 row_key 정합 + 기본문, link_url/direction/수/값목록 제거 |

- 메인 대화(3db2e80d…) 기준 실질 사용자 요청 약 **190+**건 (시스템 “briefly inform…” 제외)
