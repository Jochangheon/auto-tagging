## 갱신 기준 (2026-08-12)

- 사용자 흐름: **3단계** — 프로젝트 → 사이트 입력·분석 → 택소노미 확인·수정
- 택소노미: **카테고리+액션 1행**, 라벨 `{{버튼명}}`, 액션 크롭 이미지
- 태그 선택: 사용자 화면에서 제거, 분석 완료 시 **모든 후보 자동 포함·confirm**
- 택소노미 UI: **연결 요소/펼침 제거**
- 1단계: 「분석 대상 URL」과 「분석 페이지 목록」을 **한 목록으로 통합** (행마다 PC/MO 상태·진행 바·실행 버튼)
- 액션 이미지: 위치 정보가 비어도 페이지 job_id·`positions.json`으로 **폴백 크롭**
