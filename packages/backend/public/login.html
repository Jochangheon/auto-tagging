Microsoft 계정으로 로그인

관리자용 · Microsoft 앱 연결 (서버에 없을 때만)

일반 사용자는 이 단계가 필요 없습니다. 서버 packages/backend/.env에 AZURE_AD_CLIENT_ID를 넣으면 로그인 버튼만 보입니다.

  1. Azure 포털 → 새 등록 → 이름 아무거나 → 지원 계정: 개인 Microsoft 계정 포함
  2. 인증 → 플랫폼 추가 → 단일 페이지 애플리케이션(SPA) → 리디렉션 URI에 아래 주소 그대로
  3. 개요의 애플리케이션(클라이언트) ID만 아래에 붙여넣고 저장 → 위 Microsoft 버튼으로 로그인
